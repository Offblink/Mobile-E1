## 4. 接口契约（手机端与桌面端都在用）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/ping` | `{code:0,data:{db:"MySQL 8.0.x"}}` |
| GET/POST | `/api/mates`、`/api/mate`、`PUT/DELETE /api/mate/{id}` | 同学录（原有） |
| GET | `/api/notices?size=50` | 公告，`data` 数组，`createdAt` = `yyyy-MM-dd HH:mm` |
| POST | `/api/notice` `{title,content,author}` | 发布公告（title 空 → 400） |
| GET | `/api/messages?after=<id>&size=100` | 群消息，id 升序增量 |
| POST | `/api/message` `{sender,content}` | 发消息 |
| GET | `/api/files` | 群文件列表 |
| POST | `/api/file` | multipart：`file` + 可选 `uploader`；同名覆盖保 id |
| GET | `/api/file/{name}` | 二进制下载（中文名 OK，防路径穿越） |
| GET | `/api/rss` | 由 notice 表生成的 RSS（任务 7 XML 演示） |

服务端新增三张表：`notice`、`chat_message`、`app_file`（`DatabaseInitializer` 幂等建表，
DDL 同步在 `server/docs/schema.sql`）。文件落盘目录：`tools/tomcat/files/`（`-Dkeyou.files.dir` 可改）。

## 7. 已知坑 / 下一步

1. **桌面端首次构建慢**：Compose 依赖第一次从阿里云拉取约 2 分钟；之后有缓存。
   仓库根 Gradle 是 9.5，Kotlin 2.2.10 官方只声明支持到 8.14，实测可用（有告警）。
2. **真机连服务端**：`26.124.207.117` 是 Radmin VPN 虚拟网卡，填它必然连不上；
   要填电脑 WLAN 的 IPv4（当前 `192.168.43.15`），且手机与电脑同一网段。
3. **Android ≤ 9（API 26–28）中文分组**：已补常见姓氏首字母表（`InitialUtil.SURNAMES`，26 组 × 若干姓），
   表外生僻姓仍落 `#`；`InitialUtilTest` 钉住「单/仇/区/解/查/乐」这些姓氏读音例外。
4. **手机端公告/群文件入口**在「我的 → 日志 → 调试面板」，如果产品上想让它们彻底消失，需同时删 `RssParseActivity` /
   `DownloadActivity`——但那样任务 7 的 RSS 与任务 8 的前台服务下载就没有演示入口了。
5. **`desktop/.gradle/` 与 `build/`** 已 gitignore；`tools/tomcat/` 整体不进 git，换机器要重新放 Tomcat。
6. `reader` 依赖主 App 的 Provider authority：`com.offblink.keyou.provider.contact`（改包名会断）。
7. **桌面端默认窗口 800×600**：右上「已连接」被窗口右缘截掉一点（内容比窗口宽）。要修就在 Window 里给
   `rememberWindowState(width = 1100.dp, height = 760.dp)`，验收判据是截图里状态文字完整可见。
