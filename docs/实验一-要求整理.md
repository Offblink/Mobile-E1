## 1. 硬性约束（红线，直接关系评分）

1. **个人独立完成**，代码接受现场提问核查；抄袭/套用 = 0 分风险（作业原创性占 10%）。
2. **Git 管理**：每个任务至少一次有效提交，提交说明规范。
3. **AI 使用规范**：AI 生成代码必须逐行读懂、校验、测试后采用；关键逻辑（生命周期、事务、权限、路由）必须能手写、能讲解；AI 使用场景/提示词要点/修正过程写入报告。
4. **报告按任务 1~9 分节**记录：过程、重点代码注释、错误及改正方式；**每任务至少 1 张运行截图**；附「AI 代码修正清单」（原代码、问题、修正后代码）。
5. **评分构成**：报告 50%（基础信息 5 + 目的 5 + 过程 10 + 错误与改正 15 + 总结 15）+ 代码 50%（完成度 10 + 知识点掌握 20 + 原创性 10 + 结果正确性 10）。
6. **报告总结**须含：知识点收获、Android 原生开发难点、AI 辅助开发体会与改进方向。
7. 权限申请遵循最小必要原则；采集数据仅用于教学。

## 3. 逐任务要求

### 任务 1（2 学时）环境搭建与项目基础
- 安装 JDK 17 + Android Studio，配置 JAVA_HOME / ANDROID_HOME，命令行验证 `java -version`、`sdkmanager --list`。
- SDK Platform 34 + 模拟器镜像，创建 Pixel 系列模拟器（API 34）并启动验证。
- 新建 **Empty Views Activity** 项目 `HelloAndroid`，观察目录结构：java / res/layout / res/values / AndroidManifest.xml。
- MainActivity 中用 Log 输出 v/d/i/e 分级日志，Logcat 过滤查看。
- 思考题：① Android 四层架构及职责；② Log 五级场景与生产环境取舍。

### 任务 2（3 学时）Activity 生命周期与 Intent 通信
- 新建 FirstActivity / SecondActivity，**重写全部生命周期方法并打日志**，通过正常操作 / Home 键 / 旋转屏 / finish() 观察切换，记录日志截图。
- 显式 Intent 跳转 + Bundle 传多种类型数据 + **registerForActivityResult 接收回传**（指导书明确用结果 API，不是 startActivityForResult）。
- AndroidManifest 为 SecondActivity 配置 **standard / singleTop / singleTask / singleInstance 四种启动模式**，反复跳转观察任务栈实例数量，形成对比结论。
- 编写一个隐式 Intent（如打开系统浏览器），对比区别。
- 思考题：① 什么业务必须 singleTask；② onPause 与 onStop 执行时机差异。

### 任务 3（3 学时）UI 布局与常用控件
- 四大布局各练：LinearLayout（weight）、RelativeLayout、FrameLayout、ConstraintLayout；完成**登录页**（用户名、密码、登录按钮、注册按钮）。
- 七种以上控件：TextView、EditText、Button、ImageView、RadioButton、CheckBox、Switch 的属性/赋值/取值/点击事件；含空值校验 Toast 示例。
- **RecyclerView 联系人列表**：item 布局 + Adapter + ViewHolder + 模拟数据 + 点击事件；了解与 ListView 差异及 ViewHolder 机制（指导书给出 ContactAdapter 完整样例）。
- 综合：**简易聊天室界面**——顶部标题栏、中间消息 RecyclerView（区分左右气泡）、底部输入框 + 发送按钮。
- 思考题：① RecyclerView 优势；② 减少嵌套层级、过度绘制后果。

### 任务 4（2 学时）广播机制
- 动态注册广播接收器监听**网络变化**（CONNECTIVITY_ACTION），onDestroy 注销。
- 发送**自定义广播**：MyBroadcastReceiver 静态注册 + action，sendBroadcast 发送；对比静态/动态注册差异。
- **有序广播**：sendOrderedBroadcast + priority，观察 abortBroadcast 截断。
- 注意 Android 8.0+ 静态注册隐式广播受限的适配。
- 思考题：① 普通广播 vs 有序广播；② 8.0+ 为何限制静态注册、如何适配。

### 任务 5（4 学时）数据持久化（本任务重点，占分最重）
- 文件存储：openFileOutput / openFileInput + MODE_PRIVATE，存取一段文本。
- SharedPreferences：「记住密码」，putString/getString，理解 commit vs apply。
- **SQLite 通讯录案例**：
  - 实体类 Contact（id、name、phone、email）；
  - SQLiteOpenHelper 建 contact.db / contact 表，**VERSION=2 升级 onUpgrade 加 gender 列**；
  - ContactDao：参数化 SQL 增删改查 + **事务演示**（beginTransaction / setTransactionSuccessful / endTransaction）+ LIKE 模糊查询；
  - RecyclerView 展示，支持新增、编辑、删除、按姓名模糊查询。
- 思考题：① 三种持久化适用场景；② commit vs apply；③ 不调 setTransactionSuccessful 会怎样。

### 任务 6（2 学时）内容提供器与运行时权限
- 运行时申请 **READ_CONTACTS** 危险权限，读系统通讯录展示（指导书用 checkSelfPermission + requestPermissions 示例）。
- ContentResolver 读系统通讯录，理解 URI 与系统 Provider。
- **自定义 ContentProvider** 共享任务 5 的通讯录数据：insert/query/update/delete + UriMatcher + Manifest 注册（exported、permissions 属性）。
- **新建第二个 App** 通过 ContentResolver 跨 App 读取，验证权限管控。
- 思考题：① 普通权限 vs 危险权限；② Provider 相比直接暴露文件/库的优势。

### 任务 7（4 学时）网络技术应用
- 准备本地 Spring 后端接口返回 JSON 数组（可用任务 9 接口）。
- HttpURLConnection GET/POST：**子线程执行 + 异常捕获 + runOnUiThread 回 UI**（指导书给完整样例）。
- JSON 解析：**org.json 与 Gson 解析同一接口**，对比效率与易用性。
- 封装通用网络工具类（GET/POST、回调、主线程切换、异常统一处理）；练习 XmlPullParser 解析 RSS。
- Android 9.0+ 明文 HTTP 限制：usesCleartextTraffic 或 networkSecurityConfig；**模拟器访问本机用 10.0.2.2**。
- 思考题：① 为何禁止主线程网络请求；② Gson vs org.json 适用场景。

### 任务 8（2 学时）后台服务与定位多媒体
- MyService：startService/stopService + onCreate/onStartCommand/onDestroy 生命周期；bindService/unbindService 绑定式通信对比（指导书给 LocalBinder 样例）。
- 后台文件下载案例：IntentService（或 WorkManager / 前台服务）+ 进度通知 + 本地保存；注意 Android 8.0+ 后台限制与 **POST_NOTIFICATIONS 权限**。
- 定位：了解百度/高德 SDK 申请 Key 与接入流程，实现一次定位并显示；ACCESS_FINE/COARSE_LOCATION 运行时申请。
- 多媒体：MediaPlayer 播本地/网络音频；Intent 调系统相机拍照取缩略图。
- 思考题：① 启动式 vs 绑定式适用场景；② 8.0+ 后台限制与替代方案。

### 任务 9（2 学时）Android × SpringMVC 整合综合案例
- 后端：**Spring + SpringMVC + MyBatis（SSM）** 搭员工管理接口，REST 风格：
  - `GET /api/emps`（分页列表）、`POST /api/emp`（新增）、`PUT /api/emp`（修改）、`DELETE /api/emp/{id}`（删除），部署 Tomcat。
- 前端：整合任务 7 网络工具类，实现：
  - 启动加载分页员工列表（RecyclerView + 分页加载）；
  - 表单新增（POST JSON，Gson 序列化，Content-Type: application/json）；
  - 长按删除、点击编辑（PUT）；
  - 加载中对话框、空数据提示、网络异常统一提示。
- 联调验收：模拟器 + 本机 Tomcat 完成增删改查闭环；**Postman 先行验证接口**；**记录并解决至少 3 个联调问题**（跨域、编码、字段不匹配等）——这 3 个问题要进报告的「错误与改正」。
- 思考题：① 梳理「App 请求 → 后端 → 数据库 → 响应 → 渲染」完整链路；② 原生 vs UniApp 实现同一列表页效率对比。

## 4. 技术约束与现代适配注意（指导书自带 + 本机实测补充）

- 指导书样例面向较旧 API，多处自带适配提示，实现时必须处理：
  - `CONNECTIVITY_ACTION` 已废弃 → 需按现代 API 适配但仍要演示网络变化监听；
  - `IntentService` 已废弃 → 指导书允许用 WorkManager / 前台服务替代；
  - Android 8.0+ 静态注册隐式广播受限、后台服务受限；
  - Android 9.0+ 禁明文 HTTP；Android 13+ 通知需 POST_NOTIFICATIONS 运行时权限；
  - targetSdk、compileSdk 与指导书"SDK 34"的关系需在 SPEC 里定。
- 模拟器连本机后端：`10.0.2.2:8081`（本项目 Tomcat 端口；8080 被课堂08 旧服务占用），防火墙放行。
- 中文乱码四件套：请求头、连接流、数据库连接参数、统一 UTF-8。
- 常见报错速查（指导书原文）：NetworkOnMainThreadException、415（Content-Type）、列表不刷新（未主线程 notifyDataSetChanged）、getStringExtra null（key 不一致）、空 ContentValues 崩溃等。
